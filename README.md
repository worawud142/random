# สุ่มคำศัพท์พื้นฐาน ป.1–ป.6

เว็บแอพสุ่มคำศัพท์ภาษาไทยและภาษาอังกฤษจากเอกสารต้นฉบับ จำนวนครั้งละ 20 คำ แบ่งเป็นคำง่าย 7 คำ คำยากปานกลาง 8 คำ และคำยาก 5 คำ

## ใช้งานในเครื่อง

```bash
npm install
npm run dev
```

## Deploy บน Vercel

นำ GitHub repository นี้เข้า Vercel แล้วใช้ค่ามาตรฐานของ Next.js ได้ทันที คำสั่ง build คือ `npm run build`
